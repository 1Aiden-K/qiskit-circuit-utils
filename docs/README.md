# API Reference

The public API is organized into modules by functionality.

- [`correction`](correction.md) — Utilities for classically controlled quantum corrections.
- [`entanglement`](entanglement.md) — Utilities for entanglement protocols and distribution.
- [`measurement`](measurement.md) — Utilities for adding non-basic measurements to quantum circuits.
- [`operation`](operation.md) — Utilities for multi-qubit operations.
- [`preparation`](preparation.md) — Utilities for preparing states across qubits.
- [`transform`](transform.md) — Utilities for quantum transforms.
