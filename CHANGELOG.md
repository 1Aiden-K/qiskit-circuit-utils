## [1.0.0] - 2026-08-22

### Added

* State-preparation utilities for Bell, GHZ, W, computational basis, product, random, arbitrary statevector, Pauli eigenstates, and Bloch-sphere states.
* Measurement utilities for X, Y, Z, arbitrary Pauli, and Bell bases, including multi-qubit and pair-based operations.
* Classically controlled X, Z, and Pauli correction utilities.
* Entanglement and communication utilities including entanglement swapping, quantum teleportation, GHZ-style distribution, state transfer, and superdense coding.
* General circuit operations including multi-qubit reversal.
* Quantum Fourier transform and inverse quantum Fourier transform utilities.
* Support for Qiskit objects and integer bit specifiers throughout the public API.
* NumPy statevector input support.
* Runnable examples for Deutsch's algorithm, quantum phase estimation, and quantum teleportation.
* Generated API reference documentation for all public modules.
* Support for Python 3.11 and later, Qiskit 2.0 and later, and NumPy 2.0 and later.
* Automated testing, linting, formatting, and static type checking across supported Python versions.
